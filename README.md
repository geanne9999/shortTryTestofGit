# Interactive Mesh Gradient Wallpaper

A customizable interactive mesh gradient generator built with HTML5 Canvas and vanilla JavaScript.

## Features
- Real-time animated mesh gradient with fluid motion
- Interactive color points and customizable palettes
- High-resolution wallpaper export / capture
- Responsive and standalone (no external dependencies required)

## Getting Started
Simply open `mesh-gradient.html` (or `index.html`) in any modern web browser.
